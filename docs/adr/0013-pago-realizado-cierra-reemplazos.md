# Pago realizado confirmado cierra reemplazos del mes

Estado: aceptada

Finanzas confirma en la aplicación que se pagó fuera de ella el mes completo. Antes de esa confirmación puede preparar una nueva versión final de la preliquidación del mismo mes sin modificar las versiones previas. Después, el mes pagado no admite reemplazar su preliquidación ni reabrir los períodos de asistencia cuyas revisiones la sustentan. Esta constancia da un límite operativo verificable sin ejecutar transferencias desde Planilla.

## Consecuencias

- El estado registra al responsable y la fecha de confirmación para auditoría.
- La aplicación sigue permitiendo consultar la preliquidación pagada y sus revisiones fuente.
- El flujo de subsanación posterior al pago queda fuera de este incremento y deberá diseñarse antes de permitir nuevas correcciones de esos datos.
